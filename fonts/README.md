# Bundled fonts

Jost and JetBrains Mono WOFF2 subsets from Google Fonts, downloaded 2026-10-28.
Font files are unmodified. All subsets provided by the Google Fonts CSS are kept so Cyrillic and Kyrgyz letters remain available.

Source CSS: https://fonts.googleapis.com/css2?family=Jost:ital,wght@0,300..800;1,400..600&family=JetBrains+Mono:wght@400;500&display=swap

Licenses: Jost-OFL.txt and JetBrainsMono-OFL.txt (SIL Open Font License 1.1).
Local CSS retains the original font-face weight/style/unicode-range declarations.
